# Shock Reflection — гистерезис RR↔MR на клине

Численное исследование перехода между регулярным (RR) и маховским (MR) отражением ударных волн при обтекании плоского клина сверхзвуковым потоком. Воспроизведение классической петли гистерезиса Иванов-Chpoun на 2D Эйлеровом solver'е.

## О чём проект

Между критериями von Neumann (θ_w^N) и detachment (θ_w^D) существует **зона двойного решения**: одно и то же θ_w может соответствовать и RR, и MR. Какое именно реализуется — зависит от истории. При плавном увеличении угла клина из RR-зоны система удерживается в RR до θ_w^D; при последующем уменьшении удерживается в MR до θ_w^N. Это и есть гистерезис.

В работе:
- **Уровень A**: три типа отражения при M=3 (RR / MR / отрыв)
- **Уровень B**: cold-start sweep по углам для M=3 и M=5, определение θ_cr (= θ_w^D)
- **Уровень C**: quasi-static вращение клина при M=5, наблюдение петли гистерезиса с замкнутым путём по углам
- **Детектор тройной точки** на основе признака контактного разрыва

## Структура проекта
В каждой папки секции содержится следующее(в папке B и C дублируются раннеры - это аппендикс разработки)

```
.
├── shock_reflection/
│   ├── __init__.py
│   ├── solver.py          # 2D Euler solver (MUSCL-Hancock + HLLC + SSP-RK2)
│   ├── setup_wedge.py     # immersed wedge geometry + update_wedge_angle
│   ├── theory.py          # критические углы θ_w^N, θ_w^D
│   └── analysis.py        # детектор RR/MR и тройной точки
├── scripts/
│   ├── check_install.py             # smoke-тест
│   ├── run_levelA.py                # 3 угла при M=3
│   ├── run_levelB.py                # фазовая диаграмма θ_cr(M)
│   ├── run_levelC_loop.py           # петля гистерезиса при M=5
│   └── run_level_c_for_detector.py  # калибровка детектора
└── README.md
```

## Быстрый старт

### Уровень A — три типа отражения

```bash
python scripts/run_levelA.py
```

Выход: `results_levelA_wedge/M3_theta{15,25,35}.png`. Время: ~5 минут на современном CPU.

Ожидаемые результаты:
| θ_w  | Тип            | Почему                              |
|------|----------------|-------------------------------------|
| 15°  | RR             | θ_w < θ_w^N (= 20.87° для M=3)      |
| 25°  | MR             | θ_w > θ_w^D в MR                    |
| 35°  | Detached shock | θ_w > θ_w^crit (= 34.07° для M=3)   |

### Уровень B — фазовая диаграмма θ_cr(M)

```bash
python scripts/run_levelB.py

# для проверки одного угла без полного sweep'а:
python scripts/run_levelB.py --M 3 --theta 21
```

Выход: `results_levelB/{M3,M5}/M{3,5}_theta{...}.png` + `results_levelB/phase_diagram.png`. Время: ~80 минут.

При cold-start RR-конфигурация удерживается до критерия detachment θ_w^D, после чего происходит переход в MR. Sweep с шагом 1° даёт точность определения θ_cr порядка ±0.5°.

### Уровень C — петля гистерезиса (M=5)

```bash
python scripts/run_levelC_loop.py

# отладочный режим с укороченной релаксацией:
python scripts/run_levelC_loop.py --quick
```

Выход: `results_levelC_loop/step{...}.png` + `results_levelC_loop/triple_point_log.csv`. Время: ~25 минут.

Скрипт проходит замкнутый путь по углам:

```
18° → 22.15° → 24° → 27.5° → 30° → 27.5° → 24° → 22.15° → 18°
```

На повторно посещаемых углах (22.15°, 24°, 27.5°) на восхождении (forward) и спуске (backward) должны получаться **разные конфигурации** — это и есть прямое доказательство гистерезиса. В конце скрипт печатает сводную таблицу:

```
   theta_w     forward     backward    есть гистерезис?
   --------------------------------------------------
    18°            RR           RR     нет (одинаковы)
    22.15°         RR           MR     ДА (RR vs MR)
    24°            RR           MR     ДА (RR vs MR)
    27.5°          RR           MR     ДА (RR vs MR)
    30°            MR           —      нет (только пик)
```

### Калибровка детектора

```bash
python scripts/run_level_c_for_detector.py
```

Выход: 5 cold-start MR-картинок с маркером тройной точки + CSV-файлы полей + summary.csv. Время: ~15 минут.


Wedge: x_corner = 0.5, wedge_length = 4. CFL = 0.4 везде.
